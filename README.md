# Email Meeting Flow

AI Workplace Productivity Assistant – Prompt

Role: Act as an expert full-stack developer and AI engineer.

Objective: Build a modern, responsive web application that helps professionals automate workplace tasks using AI.

Context: Integrate three core features into one dashboard:

Smart Email Generator – Create professional emails using different tones and purposes.

Meeting Notes Summarizer – Summarize notes, extract key decisions, and identify action items.

AI Task Planner/Scheduler – Create, prioritize, and schedule tasks based on deadlines and importance.

Ensure the features work together, allowing meeting action items to transfer directly into the task planner and email drafts to be generated from meeting outcomes or tasks.

Output: A functional web application with a dashboard, sidebar navigation, intuitive forms, and a responsive interface for desktop and mobile.

Requirements: Use a professional UI, reusable components, structured AI prompts, secure AI API integration, input validation, and working buttons. Allow users to edit, copy, and save generated content. Use realistic sample data and exclude authentication and user settings.

Final Goal: Deliver one integrated AI-powered workspace that saves time, improves organization, and increases professional productivity.
